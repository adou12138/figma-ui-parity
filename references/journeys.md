# 多页用户旅程（维度 7.39）

逐页面走查看不到**跨页流程**里炸的问题。本维度把页面用真实链接串成旅程，专抓这些只在"走起来"时才暴露的缺陷：落地 404/500、落地页空白、链接点击无反应、返回后白屏、中途被弹登录页。

驱动：`scripts/node/run_journeys.cjs`。运行期观测（7.35–7.38）经 `addInitScript` 在每个文档自动装钩，旅程每步采集——旅程中炸的 JS 异常与失败请求归**它们自己的维度**，不混入 7.39。

## 一、执行方式

```
node scripts/node/run_journeys.cjs --url "https://起始页" --out ./parity-test/journeys
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--max-hops` | 2 | 每条旅程最大深度（起始页算第 0 跳） |
| `--max-links-per-page` | 12 | 每页最多展开多少条候选链接 |
| `--max-visits` | 30 | 总访问页数上限（防链接图爆炸） |
| `--allow-cross-origin` | 关 | 默认只走同源链接；开启后跨源也走（谨慎） |
| `--safety-policy` | safe | `staticOnly` 时短路不启动浏览器，7.39 记 `notRun:staticOnly 策略` |

流程：BFS 从起始页出发 → 每页稳定化后采集运行期 findings → 实时提取候选链接 → 逐条**点击**（不是 goto，链接元素本身也要验）→ 等导航/SPA 变化 → 记录步骤事实 → `goBack` 回上级继续。队列里的子页会**真的导航过去**再展开它的链接（否则每个队列节点都在当前页重走一遍，同一缺陷会被重复报 N 次）。产物：

- `journeys.json`：旅程、步骤、状态与汇总；
- `journey_findings.json`：findings 平面清单，`normalize_evidence.py` 可直接消费。同一缺陷经不同路径到达按「维度 + 属性 + 页面」去重，出现次数记在 `occurrences` 上（`summary.findingsRaw` 保留去重前总数）。

## 二、候选链接的 sound 边界

只走**真实存在**的链接，不猜业务路径。以下一律跳过并可在排查时留痕：

- 不可解析或非 http(s)（`javascript:` / `mailto:` / `tel:` / `data:` 等）；
- 跨源链接（默认；`--allow-cross-origin` 才放行）；
- 含危险词的链接（删除/退出/注销/解绑/支付…中英文各一组）；
- 下载类资源（pdf/zip/xlsx/图片等扩展名，或带 `download` 属性）；
- `target=_blank`（新标签页不跟随）；
- 同页锚点（`#foo`，不构成跨页旅程）；
- 不可见链接（点击不到；记录不判缺陷）。

## 三、判定口径（只硬判确定缺陷）

| 事实 | 判定 | 等级 |
|---|---|---|
| 落地文档响应 4xx/5xx | **confirmed** | P1 |
| 落地页可见文本 < 20 字符（近空白） | **confirmed** | P1 |
| 返回后页面近空白（goBack 后内容没恢复） | **confirmed** | P1 |
| 点击链接无任何变化（未导航、DOM 无更新） | pending | P2 |
| 已登录状态下被重定向到登录页 | pending | P1 |

后两条保守的理由：SPA 路由可能只是还没渲染完（需要更长等待），登录跳转也可能是设计使然（如会话过期引导）——**没有确定证据不落缺陷**。运行期 findings（7.35–7.38）按 `references/runtime-observability.md` 既有判据走。

## 四、安全边界

- 全程只点 `a[href]`（GET 导航），不提交任何表单、不触发写操作；
- 危险词链接默认排除，下载/新标签页不跟随；
- `staticOnly` 策略下不启动浏览器，7.39 记 `notRun` 并写明原因（门禁要求原因必填）；
- 每步点击后有界等待（点击后固定 1200ms 等导航落定 / SPA 渲染 + 稳定化流程），不会在异常页面挂死。

## 五、与其它维度的关系

- **7.32 状态残留**：旅程每步的 `goBack` 同时实测返回行为；返回后空白在 7.39 记 confirmed（旅程中断），返回后锚点/滚动/筛选项差异由 `run_state_scenarios.cjs` 的 7.32 记 pending。
- **7.35–7.38 运行期观测**：同一套钩子，旅程每步自动采集，判据不变。
